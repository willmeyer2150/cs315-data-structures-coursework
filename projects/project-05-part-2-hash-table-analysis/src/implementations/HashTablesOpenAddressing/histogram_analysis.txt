Five observations I can make from the histogram generated by the 4096 trace file.

1) After compaction, the histogram is more skewed left, indicating higher counts in the lower range of "Run Length Bins".

2) Before compaction, the skew of the data is almost even on both sides, producing almost a bell curve.

3) Total Runs
- Before Compaction: 242
- After Compaction: 824
That is a 240% increase in the number of runs. This effectively breaks up each run into shorter
lengths after compaction, making shorter runs of contiguously used spots in the hash table. The result of this would
make probing lengths much shorter which improves operations like inserts and searches.

4) Mean (AVG) Run Length
- Before Compaction: 20.02
- After Compaction: 4.97
 That is a 75.2% reduction in run length after compaction, making the table which is a significant reduction
 in contiguously USED spots in the hash table. Again, this will improve searches with probing.

 5) Median (Middle) run length
 -Before Compaction: 12
 -After Compaction: 4
 That is a 66.67% reduction in the median run length after compaction. This is, again, an increase in
 efficiency of probing. \
 It should be noted that when the median is compared with the mean for before compaction, there are many more outliers that after compaction.
    - Before Compaction Mean = 20.02 vs median = 12 run length
    - Before Compaction Mean = 4.97 vs median = 4 run length

6) 90% trigger vs 95% trigger for compaction
- Before compaction - at P90 run length, 10% of clusters are of length 44 or longer
- Before compaction - at P95 run length, 5% of clusters are of length 66 or longer
- After compaction - at P90 run length, 10% of clusters are of length 11 or longer
- After compactino - at P95 run length, 5% of clusters are of length 14 or longer

This shows that a higher trigger rate, p95, would allow for larger clusters to form, so in
this trace, a p90 run length trigger would provide more runs that are shorter with continuously USED
spots in the table. In this trace, a p90 run length trigger seems more effective than p95.

7) Max Run Length
- Before Compaction: 116
- After Compaction: 45
That is a 61.21% reduction in the maximum run length. The maximum run length is the worst case
scenario of run of elements that must be probed for API operations.
