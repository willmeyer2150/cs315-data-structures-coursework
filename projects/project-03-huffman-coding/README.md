## Implementation Details

**Data Structures Used**

- TreeNode 
  - Represents a node in the Huffman tree. Each node stores a word, its frequency, and pointers to left/right child nodes. 
- PriorityQueue 
  - A min-heap used to repeatedly extract the two lowest-frequency nodes and merge them into a parent node. 
- HuffmanTree 
  - The main class responsible for:
    - Building the Huffman tree from a vector of (word, count) pairs. 
    - Traversing the tree to assign binary codes. 
    - Writing the header and encoded bitstream.

**Algorithms**

- Tree Construction (buildFromCounts)
  - Creates leaf nodes for each (word, frequency) pair. 
  - Pushes them into a priority queue (min-heap). 
  - Repeatedly extracts the two smallest frequencies and merges them into a new parent node. 
  - Continues until a single root node remains.

- Code Assignment (assignCodesDFS)
  - Performs a depth-first traversal. 
  - Appends '0' when moving left and '1' when moving right. 
  - When a leaf is reached, assigns the prefix string as the code.

- Header Writing (writeHeaderPreorder)
  - Using preorder traversal, writes each leaf node as code.
  - single word edge case uses "0" as the code.

- Encoding (encode)
  - Builds a codebook from word/code pairs. 
  - Iterates through tokenized words, writing the representative bit codes. 
  - Wraps output to 80 characters per line.

- Memory Management (destroy)
  - Traditional Recursive delete of all tree nodes to prevent leaks.

## Implementation Details

### Overview

Completed a `Scanner` class that reads an input `.txt` file and produces a `.tokens` file containing one
lowercase token (word) per line. It follows the project’s rules for alphabet and apostrophe handling.

### Design

#### Class Responsibilities

* **`Scanner`** constructor stores the input file path.

* **`tokenize(std::vector<std::string>& words)`**
  Opens the input file, reads each token using `readWord()`, and stores tokens in a vector.
  Returns `NO_ERROR` on success or a corresponding `error_type` on failure.

* **`tokenize(std::vector<std::string>& words, const std::filesystem::path& outputFile)`**
  Calls the in-memory `tokenize()`  to fill `words`, then writes each token to an output file, one per line.

* **`readWord(std::istream& in)`**
  Reads characters one by one using `in.get(c)` with the following logic:

  - Skip non-letter separators such as digits, punctuation, whitespace, or non-ASCII characters. 
  - Start token when a letter is found. 
  - Converts uppercase A–Z to lowercase using `std::tolower(static_cast<unsigned char>(c))`. 
  - Allow an internal apostrophe only if followed by a letter. 
  - Return token when a separator or EOF is reached. 
  - Return the completed token or an empty string when no more tokens are found.
